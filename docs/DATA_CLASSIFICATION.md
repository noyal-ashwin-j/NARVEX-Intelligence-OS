# NARVEX — Data Classification & Privacy Policy

## 1. Classification Tiers

### Tier 1: PUBLIC / UNCLASSIFIED
- Public educational portals, anonymous citizen tip submission interfaces, token status verification.
- Zero intelligence or officer identities exposed.

### Tier 2: LAW ENFORCEMENT SENSITIVE (LES)
- District-level aggregate counts, historical trends, cluster density heatmaps, spatial corridor telemetry.
- Accessible only to authorized District and State officers.

### Tier 3: STATE COMMAND RESTRICTED
- Predictive AI forecast models, inter-district cross-source signal fusion, executive tactical briefings, SIEM security incident logs.
- Accessible only to State Administrators and DGP/ADGP command staff.

### Tier 4: CRYPTOGRAPHIC / IMMUTABLE
- SHA-256 block ledger (`audit_hash_chain`), provenance transformation history, cryptographic session keys.
- Read-only verifiable ledger; append-only storage.
